# 二條御所（暫名）

以永祿之變（1565）為題材的瀏覽器第一人稱刀戰 roguelike。玩家扮演足利義輝，在被圍的二條御所中收回散落的名刀，一路戰到最後。

設計文件：https://claude.ai/code/artifact/f43067fe-8da7-45de-a156-4f2bb026a99e

## 執行

不需要建置。直接用瀏覽器開啟 `index.html` 即可（所有腳本都是一般 `<script>`，`file://` 也能跑）。

## 目前進度：原型 v0.1.0

這一版只驗證「用刀砍三種敵人好不好玩」，對應設計文件的「建議的第一個原型」。

已實作：
- 射線引擎、程序生成的和室貼圖（白壁、金地襖、障子、引き戸、柱、疊、天井）
- 御所隨機生成：4×4 房間，隨機生成樹開門，部分隔間是可砍穿的障子
- 紙糊的障子與障子戸會透出對面敵人的影子與篝火的光（敵人看不到你）
- 蓄力系統：按住蓄力、放開出刀，輕／妙／重三段，每把刀的最佳區間不同；蓄力消耗氣
- 招架與一閃：招架窗口內被近戰攻擊即招架成功，之後立刻出刀為一閃（三倍傷害）
- 一之太刀：量表只靠妙段命中、招架、一閃累積；發動後斬殺視野內所有敵人，手上名刀變鈍
- 脇差 + 四把名刀，各有不同的構え、斬擊軌跡、色調與數值定位（童子切破盾、鬼丸重基礎、大典太招架、三日月高手刀），各自的鋒利度與恢復方式
- 覺悟升級：斬殺累積，三選一，只抽已持有名刀的卡，可疊加；滿 10 級後改為逐段念出辭世之句
- 時機式招架：敵人頭上的擴張圈與金色容許帶
- 敵人：槍足輕、鐵砲足輕（會誤擊同伴、會被門板擋）、門板兵（輕段彈開，重段破板，失盾後變弱）
- 止め：擊殺硬直中的敵人回血（暫定）
- 無止境湧入的敵人與戰死結算

尚未實作：火災與延燒縮圈、五個計時階段、武士、弓兵、終幕插刀與盾兵圍圈、傳說結局演出、無盡模式的獨立入口。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `js/config.js` | 所有數值：玩家、蓄力段落、五把刀、敵人、湧入節奏、地圖 |
| `js/assets.js` | 程序生成的貼圖與精靈圖；換美術改這裡 |
| `js/map.js` | 御所生成與物件擺放 |
| `js/world.js` | 碰撞、視線、射線、門、尋路 |
| `js/render.js` | 射線引擎繪製、小地圖 |
| `js/fp.js` | 第一人稱持刀、蓄力弧 UI |
| `js/combat.js` | 蓄力、出刀判定、招架、一閃、一之太刀、鋒利度 |
| `js/enemies.js` | 敵人 AI、受傷、門板、鐵砲 |
| `js/main.js` | 狀態、主迴圈、敵人湧入 |
| `js/hud.js` / `js/input.js` / `js/audio.js` | 儀表列與畫面、輸入、合成音效 |

## 操作

電腦：WASD 移動、滑鼠轉向（點擊畫面鎖定）、左鍵按住蓄力、右鍵招架、R 一之太刀、1–5／Q／滾輪換刀、M 地圖、Esc 暫停。

手機：左半邊搖桿、右半邊拖曳轉向、斬／受／換／奧按鈕。
